## 1. Loyiha maqsadi

O‘zbekiston sharoitida o‘rtacha qassobchilik biznesi uchun boshqaruv dasturi ishlab chiqilsin.

Biznes modeli:

Tadbirkor tashqaridan butun hayvonni yoki katta hajmdagi go‘shtni sotib oladi → uni bo‘laklarga ajratadi → hosil bo‘lgan mahsulotlarni kilogramm hisobida sotadi.

Dastur quyidagi jarayonlarni boshqarishi kerak:

* Butun hayvon/go‘shtni xarid qilish
* Xaridni omborga kirim qilish
* Hayvonni bo‘laklarga ajratish
* Bo‘laklangan mahsulotlarni omborga kiritish
* Ombor qoldig‘ini ko‘rish
* Mahsulotlarni sotish
* Mijozlarning debitor qarzlarini ko‘rish
* Yetkazib beruvchilarning kreditor qarzlarini ko‘rish
* Mijozlardan to‘lov qabul qilish
* Yetkazib beruvchilarga to‘lov qilish
* Xarajatlarni hisobga olish
* Tannarxni hisoblash
* Foydani hisoblash
* Kunlik/oylik hisobotlar
* Dashboard orqali biznes holatini ko‘rish

# 5. Database — SQLite

Database sifatida faqat:

```text
SQLite
```

ishlatilsin.

Django default database:

```python
DATABASES = {
    "default": {
        "ENGINE": "django.db.backends.sqlite3",
        "NAME": BASE_DIR / "db.sqlite3",
    }
}
```

ishlatilsin.

Database schema Django migrations orqali yaratiladi:

```text
python manage.py makemigrations
python manage.py migrate
```

Database uchun qo‘lda SQL yozish shart emas.

Django ORM asosiy database abstraction bo‘lsin.

# 12. Butchering — Hayvonni bo‘laklash

Bu tizimning asosiy qismi.

Modellar:

```text
Butchering
ButcheringOutput
```

Masalan:

```text
Kirim:
420 kg
```

Bo‘laklash:

```text
Lahm        150 kg
Qovurg‘a     45 kg
Son          65 kg
Kurak        50 kg
Bo‘yin       25 kg
Qiyma        30 kg
Suyak        35 kg
Yog‘         15 kg
Chiqit        5 kg
```

Tizim avtomatik hisoblasin:

```text
Input weight
Output weight
Difference
Yield %
```

Formula:

```text
output_total =
SUM(all outputs)

difference =
input_weight - output_total

yield_percentage =
(output_total / input_weight) × 100
```

Output inputdan katta bo‘lsa, operatsiya saqlanmasin.
